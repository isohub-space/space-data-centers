# Payload — "ESA Taps Edge Aerospace for Space Cloud Contract"

## Reported (what the source says)
- ESA **Space Cloud** programme contracted **Edge Aerospace** (Luxembourg, founded Sept 2024) to develop an architecture and use-case roadmap for orbital data centres, analyse commercial viability, and identify European commercial/civil/defence applications. Value and timeline not stated.
- Edge holds **four other ESA contracts** and demonstrated orbital data processing on **SpaceX Transporter-16 (March 2026)**.
- CEO Jarosław Jaworski: ESA's first goal "is to find out in a structured, very analytical way if [orbital data centers] make sense"; and: *"We think that only SpaceX, through its extreme vertical integration, would be able to do what most of the folks from ODC claim."*
