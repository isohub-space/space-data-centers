# Assessing the added value of onboard EO processing with the IRIDE HEO service segment (Italy)

## Reported (what the source says)
- Evaluates onboard processing within **Italy's IRIDE** EO programme (ASI/ESA, PNRR-funded); the **HEO ("Hawk for Earth Observation") segment** enables "onboard generation of data products, allowing information extraction earlier in the processing chain".
- Quantified capabilities: **sub-3 m GSD**; **3 ha minimum mapping unit**; "enhanced system responsiveness through reduced downlink latency and bandwidth constraints".
- Case study: **burnt-area mapping**; positioned as **complementary to Copernicus** services for "emerging low-latency EO service architectures".
- No percentages of latency or downlink savings in the abstract.
