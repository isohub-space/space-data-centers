# ESA taps Kepler to lead HydRON Element 3 (€18.6 M) — "Fibre in the Sky" moves to a third element

## Reported (what the source says)
- **HydRON** = High-throughput Optical Network; ESA's sovereign optical "fibre in the sky", **terabit-per-second** capacity across orbits.
- **Element 1** (Oct 2024): **Kepler**, **$39 M**, ten-satellite demonstration system.
- **Element 2** (Feb 2025): **Thales Alenia Space**, satellite "collector" for LEO data relay.
- **Element 3** (17 Apr 2026): **Kepler**, **€18.6 M ($22 M)**, host platform for multiple optical terminals from **Tesat, Mbryonics (IE), Astrolight (LT)** plus a **Vyoma** SSA payload.
- Canada is "the only non-European cooperating state of ESA" — which is how a Toronto company primes an ESA sovereign network.
- No launch dates, no ARTES ScyLight budget line, no edge-compute mention.

## Derived (our arithmetic — formula shown)
- Public HydRON awards opened so far: $39 M + €18.6 M (+ undisclosed Element 2) ≈ **€55 M+** — small against IRIS² (€10.6 B) but it is the **only European programme building the ISL/relay layer EO edge compute needs**.

## Relevance to the Entrant
- HydRON is where a **European EO edge-compute node would plug into a sovereign optical backbone**; an entrant with ground-segment heritage should be visible to ESA's ScyLight/HydRON team as a *user* of the network (demonstration payloads, use cases).
- Terminal supplier base for Europe = **Tesat, Mbryonics, Astrolight** (plus Rocket Lab-owned Mynaric). That is the shortlist for any the Entrant downlink/ISL design.
