# space-data-centers — repo contract

A **public** intelligence vault on **orbital / space data centres**: orbital compute, launch
economics, EO edge processing, competitors, programmes, funding. It answers one question for
a **fictitious entrant** ([[scenario/entrant]]): *where is a defensible position in this
market, considering every factor and competitor?* The vault is maintained weekly by an
automated sweep (`.github/workflows/weekly-intel.yml`) and reviewed by a human before merge.

## Conventions

- **Every folder has an `_index.md`.** Add a line when you add a file.
- **`intel/` is `raw → wiki → output`.** Capture lands in `intel/raw/` (one note per
  source, `YYYY-MM-DD-<publisher>-<slug>.md`, date = publication date, template
  [[templates/intel-note]]). Only cleaned, linked analysis is promoted to `intel/wiki/`
  (one note per *idea*, not per source). `intel/output/` holds deliverables and the
  **derived** dashboard data (`intel/output/derived/dashboard.json`, regenerated by
  `scripts/build_dashboard.py`, never hand-edited, never authoritative). Don't cite `raw/`
  from `output/`.
- **Front-matter on every note** (`type:`, `tags:`); tags lowercase `#type/subtype`.
- **Every figure carries its source and a provenance label**: *reported* (what the source
  says), *primary* (what the underlying paper/filing says) or *derived* (our arithmetic,
  formula shown). A press summary is not the primary source; when a paper exists, open it
  and record where press and paper disagree. A figure taken from a search snippet is marked
  "(snippet, not opened)".
- **The Entrant is fictitious.** Advice sections address *the Entrant*; they never name a
  real company as the subject of the advice. Competitors are named; the subject is not.
- **Run the gate after any edit:** `python3 scripts/validate_notes.py` (schema, indexes,
  links), `python3 scripts/build_dashboard.py` (derived data), `python3
  scripts/check_public_safe.py` (forbidden tokens). CI runs the same three on every push.

## Public-safety rule

This repo is public and its history is permanent. **No real person, no private negotiation,
no private-estate identifier** (other repositories, trackers, machine paths, business
context outside what the cited sources publish) may appear anywhere: notes, commit
messages, PR titles and bodies, workflow logs. `scripts/check_public_safe.py` enforces a
digest-stored forbidden list over tracked files and commit messages; a hit is a failed
build, not a style note. If you need to add a token to the list, use `--add` — never write
the token into the repo.

## Attribution

No AI-attribution lines in commits or PRs: no `Co-Authored-By` for an AI tool, no session
links, no "generated with" footers. The weekly sweep is a maintainer, not an author.
